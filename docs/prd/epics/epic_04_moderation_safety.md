# epic-04-moderation-safety — 审核、风控与社区健康

> 约束回顾：聚焦中国大陆中文用户；“创业点子”为可认领/加入的微项目想法（非临时工作）；MVP ≤ 6 个月、预算 ≤ ¥1000；短期北极星：日活发帖量（DAU Post）。

## 1. 目标
- 在低预算下建立**可落地的内容审核与基础风控**，确保社区聚焦“做点子”，降低骚扰/欺诈与违规风险。

## 2. 用户故事
1. 作为普通用户，我不希望看到**违规或广告灌水**内容。
2. 作为发起人/参与者，我希望能**举报**恶意骚扰或虚假承诺，并获得处理反馈。
3. 作为运营，我需要**轻量后台**查看待审内容、处理举报、拉黑与降权。

## 3. 功能需求
### 3.1 内容审核（文本/图片/GIF/链接描述）
- 发布与里程碑提交触发**规则引擎**：敏感词、黑名单域名、图片基础检测（第三方或自研词表）。
- 可疑内容进入**待审队列**（灰度发布/仅作者可见），运营台批量处理。

### 3.2 用户举报
- 对帖子/评论/任务进行举报；举报类型（广告/辱骂/违法/抄袭/色情…）。
- 举报处理流：受理→判定→执行（删除/打回/禁言/封禁）→通知申诉入口。

### 3.3 行为风控
- 频控：单位时间发帖/评论上限；新号期权重降低。
- 降权：长期无推进的点子自动降权，重复违规的账号关联内容降权。

### 3.4 黑白名单与封禁
- 用户、设备、IP 维度；封禁级别（临时/永久）。

### 3.5 运营后台（最小集）
- 待审队列、举报工单、账号状态管理、内容检索、操作日志。

### 3.6 可观测性
- 审核拦截率、误杀率、举报响应时长、违规复发率。

## 4. 非功能
- **时效**：高风险词条**同步拦截**；其他 ≤ 12 小时内人工复核完成。
- **合规**：保留操作审计日志 ≥ 180 天；用户协议/社区公约可见。
- **成本**：自研词表 + 免费/低价 API，人工审核走“值班+峰值支援”。

## 5. 验收标准
- 违规内容外显率 ≤ 2%。
- 用户举报受理至初判中位数 ≤ 6 小时。
- 误杀率 ≤ 3%，且有申诉恢复通道。

## 6. 依赖与风险
- **依赖**：账户系统、内容存储、运营台、通知中心。
- **风险**：词表维护成本；误杀导致创作受阻（需申诉与白名单）；图片/链接审核盲区。
