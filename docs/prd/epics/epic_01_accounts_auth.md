# epic-01-accounts-auth — 账户与登录

> 约束回顾：聚焦中国大陆中文用户；“创业点子”为可认领/加入的微项目想法（非临时工作）；MVP ≤ 6 个月、预算 ≤ ¥1000；短期北极星：日活发帖量（DAU Post）。

## 1. 目标
- 以最低摩擦完成注册登录与基础资料，支撑发布/认领点子与通知触达。
- 为后续信誉与协作提供可识别的用户身份与技能标签。

## 2. 用户故事
1. 作为新用户，我希望用**手机号或微信**10 秒内完成登录，以便立即发帖。
2. 作为参与者，我希望补充**技能标签与作品链接**，让别人快速判断是否合适一起做。
3. 作为点子发起人，我希望**收到系统通知**（评论/申请加入），不必反复刷新。

## 3. 功能需求
### 3.1 登录/注册
- 手机号短信登录；微信 OAuth 登录（可二选一起步）。
- 首次登录落地到“完善资料”轻向导（可跳过）。

### 3.2 用户资料
- 必填：昵称；可选：城市、简介、技能标签（多选）、外部联系方式（可隐藏）。
- 公开页：可查看其**参与点子/提交里程碑**计数与最近三条成果凭证缩略。

### 3.3 通知中心
- 站内通知：评论/回复、加入申请、@提及、里程碑通过/打回。
- 订阅方式：站内红点；（预算允许）微信服务通知/短信。

### 3.4 设置与隐私
- 资料公开范围（公开/仅成员可见）；可屏蔽@。
- 账号安全：设备管理（最近登录记录）、退出所有设备。

### 3.5 埋点（面向 DAU Post）
- `login_success`、`profile_completed`、`post_create_clicked`、`post_published`。

## 4. 非功能
- **可用性**：移动端 H5 首屏 < 2.5s；关键路径 ≤ 3 步完成登录。
- **合规**：最小化收集；提供隐私政策与用户协议入口。
- **可扩展**：预留信誉分与第三方作品集（GitHub/Behance 链接）。

## 5. 验收标准
- 90% 新用户 ≤ 30 秒完成登录。
- 用户资料完成率（含 ≥3 个技能标签）≥ 40%。
- 通知送达（站内）成功率 ≥ 99%。

## 6. 依赖与风险
- **依赖**：短信服务/微信开放平台；通知队列；用户/会话存储。
- **风险**：短信成本与滥用；微信审核周期；多端会话异常。
