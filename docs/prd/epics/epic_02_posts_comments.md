# epic-02-posts-comments — 点子发布、发现与讨论

> 约束回顾：聚焦中国大陆中文用户；“创业点子”为可认领/加入的微项目想法（非临时工作）；MVP ≤ 6 个月、预算 ≤ ¥1000；短期北极星：日活发帖量（DAU Post）。

## 1. 目标
- 提供**结构化点子模板**与**轻讨论**，驱动日活发帖量与高质量内容。
- 支持按领域/阶段发现与关注，形成内容循环。

## 2. 用户故事
1. 作为发起人，我能按模板**快速发布点子**（含最小验证与里程碑）。
2. 作为浏览者，我能**筛选我感兴趣的领域**与**阶段**，并关注/收藏。
3. 作为参与者，我能在评论区**交流细节**并@他人。

## 3. 功能需求
### 3.1 点子发布模板（结构化）
- 字段：标题、目标人群/痛点、解决方案雏形、**最小验证任务**、里程碑（≤3）、所需角色位、标签（行业/技术/场景）。
- 草稿与发布；预览；一键复制官方模板（M1 可扩展模板库）。

### 3.2 发现/筛选
- 筛选：领域（本地生活/教育/工具/AI/内容/IP…）、阶段（灵感/已立项/验证中/有 Demo）、所需技能。
- 排序：最新/活跃/里程碑完成数。
- 首页卡片流 + 「今日高互动」榜。

### 3.3 互动
- 评论/回复、@用户、表情/点赞、收藏/关注点子。

### 3.4 关注流
- 我关注的点子/用户的动态集合（新评论、新里程碑、招募位变化）。

### 3.5 埋点
- `post_publish_success`、`post_view`、`post_filter_apply`、`comment_publish`、`follow_idea`。

## 4. 非功能
- **可用性**：表单自动保存草稿；移动端输入友好；发布校验强制包含“最小验证任务”。
- **性能**：列表分页；首屏加载 < 2.5s；筛选响应 < 400ms（后端纯读）。

## 5. 验收标准
- 新用户首 24 小时**发帖转化率 ≥ 15%**。
- 帖子含“最小验证任务”的占比 ≥ 80%。
- 发现页筛选平均响应时间 < 400ms。

## 6. 依赖与风险
- **依赖**：账户系统、标签字典、搜索/过滤能力。
- **风险**：模板门槛过高→发帖率下降（需 A/B 简化字段）；低质灌水（依赖审核策略）。
